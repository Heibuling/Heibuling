## v0.2.7 — 2026-10-26

### 修复
- **聊天页输入框被键盘遮掉一半**：改为 `statusBarsPadding() + (navigationBars ∪ ime)`，键盘弹出时输入框完整可见（实测输入框底边 1818 &lt; 键盘顶 1820）
- **涂鸦被压扁**：画布宽高比写进消息，回放按原始比例渲染。实测画布 1080×1500 的涂鸦渲染比例 0.73，与原始一致
- **悬浮球面板每次都要重选发送对象**：记住上次发送的人，展开面板默认选中
- **关闭悬浮球后一进 App 又被强制打开**：关闭状态持久化，重启后保持关闭（已实测）
- **侧滑返回收不起面板**：改用 Android 13+ 官方 `OnBackInvokedDispatcher` 注册返回回调；键盘收起时也会自动收起面板（已实测）

### 新增
- **聊天记录显示每条消息发送时间**，自己发的还带「已送达 ✓ / 已查看 ✓✓」；悬浮气泡右上角也显示时间
