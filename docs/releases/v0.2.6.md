## v0.2.6 — 2026-10-25

### 修复
- **自更新在慢网络下会下载失败**：实测直连 GitHub 约 100 KB/s，25 MB 的安装包下到 **99% 被连接重置**；
  旧实现失败后删除文件重头再来，结果永远装不完。现改为：
  - **断点续传**（带 `Range` 头继续下载，失败保留已下载部分）
  - **同源重试 3 次**，并有 **4 个下载源兜底**（GitHub 直连 → gh-proxy → ghproxy.net → ghfast.top）
  - 读超时放宽到 60 秒；进度显示「已下载 x.x MB / y.y MB + 百分比」
