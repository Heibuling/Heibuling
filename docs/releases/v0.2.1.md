## v0.2.1 — 2026-10-25

### 修复
- **权限向导第 4 项保活教程**只有当前品牌、且读完仍是红叉。现改为卡片内可展开，顶部一排品牌芯片可手动切换（vivo / iQOO、OPPO / 一加、小米 / Redmi、华为 / 荣耀、三星、其他），每套品牌路径独立；点「我已按教程设置完」后 ❌ 变 ✅ 并持久化保存，另有「重新设置」
- **昵称被重置为 Eric**：`ensureInitialized()` 在生成 uid 时无差别覆盖昵称，把用户在昵称页输入的名字冲掉了。现改为只在字段为空时写默认值（绝不覆盖已有昵称），且昵称页改为先建身份再写昵称
- **连点「邀请好友」产生多个"等待对方加入"**：现在有未使用的邀请时不再静默新建，改弹邀请管理弹窗，可查看邀请码 / 删除 / 再新建（上限 5 个）
