## v0.1.0 — 2026-10-25

首个可用版本。

### 新增
- 复用 ntfy.sh 公共推送通道 + 自研 Android 客户端（不依赖 Firebase / FCM）
- **顶部半透明气泡**：毛玻璃 + 高光边缘、5 秒自动消失、点击立即关闭；支持排队依次显示
- **邀请码配对**：创作者生成邀请码 → 好友粘贴配对 → 自动建立好友关系
- 朋友列表、会话页、最近 100 条历史记录（轻量 JSON 存储，原子写入）
- **图片**：两段式发布（先上传附件再发信封），接收端先弹占位框、下载完成后原地替换
- **语音**：20 秒上限录制 + 32 点波形 + 气泡内点击播放
- **涂鸦**：全屏画布 + 笔画归一化存储 + 接收端逐笔回放
- **悬浮球**：可拖动吸附、点击展开紧凑输入面板、可唤起输入法
- **回执状态机**：已送达（弹框成功）/ 已查看（对方点掉），头像旁状态点 + 静默通知
- 权限向导、开机自启、常驻通知文案池（按时段问候 + 数据彩蛋 + LRU 去重）
- 指数退避重连 + `since` 断线补收
- 签名 release APK
