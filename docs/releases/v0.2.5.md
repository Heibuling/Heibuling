## v0.2.5 — 2026-10-25

### 新增
- **应用内自更新**（以后不用再手动发安装包了）：
  - 每天自动检查一次新版本，主页也可手动点「检查更新」
  - 发现新版本 → 弹窗展示更新说明 → 应用内下载（带进度）→ 调起系统安装器覆盖安装
  - 版本信息来源为仓库 `docs/version.json`，多路兜底（GitHub 直连 / gh-proxy 镜像 / jsDelivr），适配国内网络
  - 覆盖安装使用同一签名，**无需卸载，聊天记录与配对关系都不会丢**

> ⚠️ 自更新能力只存在于 v0.2.5 及以后。**v0.2.5 需要最后一次手动安装**，之后即可在 App 内一键更新。
