
# Heibuling 安装与使用说明（给朋友看的版本）

这是一款**小圈子用的"弹幕式"消息 App**：小黑给你发文字/表情/图片/语音/涂鸦时，
你的手机屏幕顶部会**弹出一条半透明玻璃气泡**，约 5 秒后自动消失；你也可以反过来发给他。

只有你和小黑会用，不对外发布，**不需要注册账号**。

---

## 一、安装（约 1 分钟）

1. 小黑会通过微信/网盘把一个 **APK 文件**（`Heibuling-v0.2.0.apk`）发给你；
2. 点开安装。若提示"未知来源应用"，允许即可（vivo/iQOO：弹窗选「继续安装」；
   若被拦截，去 设置 → 安全 → 更多安全设置 → 允许安装未知来源应用）；
3. 装好后桌面出现一个深色气泡图标的 **Heibuling**。

> 需要 **Android 10 或更高**。

---

## 二、第一次打开：4 件事

1. **权限向导**：逐项点开并允许 —— 通知权限、**悬浮窗权限（最关键）**、电池优化白名单；
   第 4 项点「查看说明」，会**按你的手机品牌**显示对应的保活路径（vivo/iQOO / OPPO / 小米 / 华为荣耀各不相同）；
2. **起昵称**：向导走完会让你输入昵称——这个名字会显示在对方看到的气泡上，以后可在主页改；
3. 进入主页后会看到小黑（如果他还没配对，你会收到一串邀请码）；
4. **把 Heibuling 加到后台白名单**（见第四部分，这步不做会掉线）。

---

## 三、配对

**情况 A：小黑已经把邀请码发给你了**
1. 打开 Heibuling → 点 **「我收到邀请码（粘贴配对）」**；
2. 把整段（以 **NTP1-** 开头的一长串）粘进去 → 点「配对」；
3. 看到"配对成功，已向「小黑」报到"就好了。

**情况 B：你还没收到邀请码** → 找小黑要一个，或让他先点「邀请好友」生成。

---

## 四、后台保活（**不做这步，划掉后台就会断线**）

### 如果你的手机是 vivo / iQOO（OriginOS / Funtouch）
1. 设置 → 应用与权限 → 权限管理 → **自启动** → 允许 Heibuling
2. 设置 → 电池 → **后台耗电管理** → Heibuling → 允许「**后台高耗电**」
3. 设置 → 应用与权限 → 权限管理 → **悬浮窗** → 允许
4. 打开**最近任务** → 长按 Heibuling 卡片 → 点「**锁定**」
5. 设置 → 电池 → 关掉省电模式，或把 Heibuling 加入白名单

### 如果你是 OPPO / 一加 / realme（ColorOS）
1. 设置 → 应用 → 应用管理 → Heibuling → 允许**自启动** 与 **关联启动**
2. 设置 → 电池 → 应用耗电管理 → Heibuling → 允许**后台活动**
3. 权限管理 → **后台弹出界面** → 允许
4. 最近任务 → **下拉卡片加锁**

### 如果你是小米 / Redmi
1. 设置 → 应用设置 → 应用管理 → Heibuling → **自启动**打开
2. 同页 → 其他权限 → **显示在其他应用上层** → 允许
3. 设置 → 省电与电池 → 应用智能省电 → Heibuling → **无限制**

### 如果你是华为 / 荣耀
1. 设置 → 应用 → 应用启动管理 → Heibuling → 改为**手动管理**（三项全开）
2. 设置 → 电池 → 更多电池设置 → 打开「休眠时始终保持网络连接」

---

## 五、怎么用

### 收消息
- 对方发来时，**屏幕顶部弹出半透明气泡**（5 秒后自动消失）；
- **点一下气泡**立刻关掉 —— 对方会看到"你点掉了消息"；
- 消息会留在会话列表里（只保留最近 100 条）。

### 发消息（两种方式）
1. **打开 App**：点好友 → 输入 → 发送；下方还能发**图片 / 涂鸦 / 语音**；
2. **不离开当前 App**（推荐）：桌面有一个可拖动的 **💬 悬浮球**，点一下就能选好友、打字、用 8 个快捷 emoji、发送。

> 悬浮球可拖动，松手自动贴边并记住位置。
> **涂鸦支持笔迹回放**：你画的每一笔，对方会一笔一笔看到，而不是突然出现一张图。

---

## 六、收不到气泡？按顺序检查

1. **悬浮窗权限**被收回了？（设置里搜"悬浮窗"确认 Heibuling 是允许）
2. App 被"一键清理"干掉了？→ 最近任务里**给它加锁**
3. 电池把 Heibuling 冻结了？→ 改成"无限制 / 允许后台高耗电"
4. 打开 App 看一眼，如果顶部有权限提示，点一下补授权；
5. 还不行就让小黑再发一条（打开 App 会自动重连）。

---

## 七、隐私说明

- 消息**没有端到端加密**，经公共推送服务 **ntfy.sh** 中转；
- 每条「你 ↔ 小黑」的通道名是 26 位随机字符，**等同于密码**，界面上不显示（也请不要截图给别人）；
- **图片/语音/涂鸦在服务器上只保留 3 小时**：超过 3 小时才开机可能显示"已过期"，让对方重发（文字不受影响）。
